# 海陆站三台风机数据分析项目

## 项目简介

本项目对三台风机（2023年1月至11月）的运行数据进行全面深入的分析，旨在发现数据规律、识别异常点，并提出优化建议。

## 数据文件

- `1__风机数据.csv` - 风机1号运行数据
- `2__风机数据.csv` - 风机2号运行数据  
- `3__风机数据.csv` - 风机3号运行数据

每个文件包含约40,800条记录，每10分钟采样一次，包含以下主要字段：
- 统计时间
- 网侧有功功率（最小、平均、最大）
- 风向角度
- 风速（最小、平均、最大、标准差）
- 对风角度
- 偏航位置

## 环境要求

## 分析内容

### 1. 数据预处理
- 数据加载与格式转换
- 缺失值处理（前向/后向填充）
- 异常值识别（负功率、异常高功率）
- 数据质量评估

### 2. 运行统计分析
- **发电量统计**：总发电量、日发电量、月发电量
- **运行时长**：有效运行时长、停机时长
- **利用小时数**：基于额定功率2500kW计算
- **容量系数**：实际发电量与理论发电量的比值
- **可用率**：运行时长占总时长的百分比
- **风速统计**：平均风速、风速分布

### 3. 性能对比
- 三台风机发电量对比
- 运行效率差异分析
- 可用率和容量系数对比
- 风资源利用情况对比

### 4. 异常检测
- **异常停机检测**：高风速下功率异常低的情况
- **低效运行检测**：功率系数异常低的时段
- **数据异常检测**：功率突变（10分钟内变化>1000kW）

### 5. 可视化展示
- 时间序列趋势图
- 风速-功率散点图（功率曲线）
- 月度/日度对比柱状图
- 性能指标对比图

### 6. 优化建议
基于分析结果提出：
- 预防性维护建议
- 运行参数优化方向
- 故障响应改进措施
- 性能提升空间

## 分析方法说明

### 关键指标计算

**发电量 (kWh)**:
```
发电量 = Σ(平均功率 × 采样间隔)
     = Σ(平均功率(kW) × 10/60小时)
```

**利用小时数**:
```
利用小时数 = 总发电量 / 额定功率
```

**容量系数 (%)**:
```
容量系数 = (总发电量 / (额定功率 × 总时长)) × 100%
        = (平均功率 / 额定功率) × 100%
```
注：容量系数表示实际发电量与理论最大发电量的比值

**可用率 (%)**:
```
可用率 = (运行时长 / 总时长) × 100%
```

### 异常检测逻辑

1. **异常停机**: 风速 > 5 m/s 且 功率 < 100 kW
2. **低效运行**: 效率指标 = 功率 / (风速² + 1) 低于10%分位数
3. **功率突变**: 相邻10分钟功率变化 > 1000 kW

## 注意事项

1. 数据文件较大（约12MB），加载需要一定时间
2. 生成可视化图表时会采样数据以提高性能
3. 中文显示需要系统支持中文字体（如SimHei、WenQuanYi等）
4. 建议在具有至少4GB内存的环境中运行
5. 首次运行可能需要1-2分钟完成全部分析
